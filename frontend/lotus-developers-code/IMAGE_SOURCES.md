# Sample property image sources

The seeded property photos are linked from Unsplash's CDN. They are visual references for the sample residence concepts and do not depict verified Stark Properties inventory. Replace them with approved property photography in Django admin.

| Sample residence | Photo source |
| --- | --- |
| The Verdant House | [Modern villa collection](https://unsplash.com/s/photos/modern-villa) |
| The Courtyard Residence | [Modern house with large windows and sunroom](https://unsplash.com/photos/modern-house-with-large-windows-and-sunroom-g_B92WafICI) |
| The Skyline Collection | [Modern apartment building with balconies](https://unsplash.com/photos/modern-apartment-building-with-balconies-against-bright-sky-gjhCscBW1t4) |
| The Quiet Grove | [Cabin nestled in the woods](https://unsplash.com/photos/a-cabin-nestled-in-the-woods-surrounded-by-trees-9PSUpqr0Kgg) |

Each residence also has two additional Unsplash gallery photos seeded by migration `0005_property_image_gallery`. You can replace or add gallery photos from the property's **Property gallery images** inline section in Django admin. Gallery photo entries support uploaded JPG, PNG, and WebP images or an external image URL.
